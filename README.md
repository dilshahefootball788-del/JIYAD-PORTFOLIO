# JIYAD Portfolio

A responsive personal creative portfolio built with plain HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy to Netlify
1. Extract this ZIP.
2. Open https://app.netlify.com/projects/jiyad-portfolio
3. Choose the manual deploy / drag-and-drop option, or open https://app.netlify.com/drop.
4. Drag the extracted `JIYAD-PORTFOLIO` folder (the folder containing `index.html`) into the deploy area.
5. Wait for Netlify to finish publishing.

## Before sharing publicly
- Replace the sample project artwork with actual finished projects.
- Update the Instagram link in `index.html`.
- Add your WhatsApp number to the `wa.me` link (country code + number, digits only).
- Check all text and contact details.
